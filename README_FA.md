# سامانه جامع بالینی هوش مصنوعی رادیولوژی دندان (DentalAI Multi-Modality Studio)

> [English Documentation is available in README.md](README.md)

سامانه پیشرفته تشخیص، مکان‌یابی عوارض دندانپزشکی، کادرکشی هوشمند تک‌دندان، محاسبه درصد احتمال درستی و خطا، و چارتینگ خودکار بر اساس **استاندارد جهانی فدراسیون دندانپزشکی (FDI World Dental Federation)** برای هر دو نوع رادیوگرافی:
1. **رادیوگرافی پانورامیک فک (OPG):** بررسی کل ۳۲ دندان، دندان‌های نهفته، ضایعات پری‌آپیکال ریشه، کیست‌ها و پوسیدگی‌ها.
2. **رادیوگرافی داخل‌دهانی بایت‌وینگ (Bitewing / BW):** تشخیص تخصصی پوسیدگی‌های مخفی بین‌دندانی (پروگزیمال)، بررسی سلامت لبه پرکردگی‌ها و ترمیم‌ها، و وضعیت استخوان کرستال.

---

## 🌟 قابلیت‌های برجسته سامانه

1. **طرح گرافیکی شماتیک ۳۲ دندان (Interactive SVG Odontogram):**
   - ترسیم دقیق شماتیک تک‌تک دندان‌ها با تفاوت آناتومیک تاج و ریشه:
     - دندان‌های آسیای بزرگ بالا (۳ ریشه) و پایین (۲ ریشه)
     - دندان‌های پره‌مولر (۲ ریشه)
     - دندان‌های نیش و پیشین (تک‌ریشه)
   - خط میانی قوس فکی (Dental Midline) و تفکیک ۴ ربع فک (Quadrant 1 to 4).
   - نمایش رنگی وضعیت هر دندان (سبز: سالم، قرمز: پوسیدگی، آبی: ترمیم، نارنجی: نهفته، بنفش: ضایعه ریشه، خاکستری: خارج از کادر تصویر).
   - کلیک روی هر دندان جهت مشاهده آنی کارت وضعیت، نام فارسی، شماره استاندارد FDI، موضع آسیب و طرح درمان.

2. **سیستم استاندارد نام‌گذاری و شماره‌گذاری دندان‌ها (FDI Two-Digit System):**
   - جایگزینی هرگونه شماره‌گذاری تصادفی با شماره‌های مصوب دندانپزشکی:
     - **فک بالا راست (ربع ۱):** دندان‌های ۱۱ تا ۱۸
     - **فک بالا چپ (ربع ۲):** دندان‌های ۲۱ تا ۲۸
     - **فک پایین چپ (ربع ۳):** دندان‌های ۳۱ تا ۳۸
     - **فک پایین راست (ربع ۴):** دندان‌های ۴۱ تا ۴۸
   - نمایش نام کامل فارسی (مثلاً: *دندان آسیای اول بالا راست (#16)*، *دندان پره‌مولر دوم پایین چپ (#35)*).

3. **کادرکشی دقیق و ظریف دور همان دندان آسیب‌دیده (Single-Tooth Precision Bounding Boxes):**
   - اصلاح کادرها جهت قرارگیری دقیق دور ۱ دندان هدف (عرض ۴۰ الی ۵۰ پیکسل متناسب با عرض دندان) بدون دربرگیری دندان‌های مجاور.
   - درج شماره FDI و درصد اطمینان هوش مصنوعی روی هر کادر.

4. **تشخیص خودکار و پشتیبانی هم‌زمان از OPG و بایت‌وینگ (Auto Modality Detection):**
   - تشخیص اتوماتیک نوع رادیوگرافی از روی نسبت ابعاد تصویر (OPG در برابر Bitewing).
   - تحلیل تخصصی رادیوگرافی‌های بایت‌وینگ راست (Right BW) و چپ (Left BW) با فوکوس روی پوسیدگی‌های بین‌دندانی دندان‌های خلفی (پوسیدگی‌های پروگزیمال مزیال/دیستال).

5. **پیشنهاد حساسیت بهینه مدل (Optimal Sensitivity Preset):**
   - تنظیم پیش‌فرض و پیشنهادی روی **۱۵٪ (⭐ حالت بهینه)** برای ایجاد بهترین تعادل بین کشف پوسیدگی‌های پنهان و عدم گزارش خطای کاذب.
   - دکمه‌های سریع برای حالت حساس (۸٪) و سخت‌گیرانه (۲۵٪).

6. **محاسبه دقیق درصد احتمال درستی و خطا:**
   - **درصد احتمال درستی (Confidence %):** کالیبره‌شده برای اطمینان کلینیکی.
   - **درصد احتمال خطا (Error Margin %):** حاشیه ریسک آماری.
   - تعیین دقیق موضع آناتومیک آسیب (تاج، سطح جونده، بین‌دندانی، پالپ، اپکس ریشه، استخوان فک).

7. **گالری برش‌های زوم‌شده (Zoomed ROIs) و گزارش رسمی قابل چاپ PDF:**
   - نمایش برش باکیفیت و بزرگنمایی‌شده از هر دندان دارای عارضه.
   - چاپ یا ذخیره کارنامه بالینی دندانپزشکی با فرمت رسمی.

## 🚀 نحوه نصب و اجرا

### ۱. پیش‌نیازها
ابتدا پیش‌نیازهای پروژه را نصب کنید:
```bash
pip install -r requirements.txt
```

### ۲. اجرا با اسکریپت ویندوز (تک‌کلیک)
کافیست روی فایل زیر دو بار کلیک کنید:
```cmd
run_app.bat
```
مرورگر به طور خودکار باز شده و برنامه در آدرس زیر اجرا می‌شود:
👉 **http://localhost:8000**

### ۳. یا اجرا با خط فرمان:
```bash
python server.py
```
